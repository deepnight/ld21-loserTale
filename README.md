# A tale about life, death and a loser (Ludum Dare 21)

A short compo for the Ludum Dare 21 (theme: Escape).

I couldn’t participate to the whole 48h LD, so I decided to try to make a game in really short time (I had my Sunday free). So, this game was basically created in 9 hours (from Sunday 11:30am to 8:30pm).

I wanted to try to make something complete within one normal business day (8h), just to see what I can achieve, when I really commit to it.

Note : I’m sorry I didn’t have time to include the happy ending branch :) The assets where almost ready (they are in the PSD source file), but I was running short on time to include it… Maybe a later version ?
